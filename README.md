# MailGuard — Email Validation Tool

MailGuard is a responsive email-validation interface designed to check email formatting and present clear, user-friendly feedback.

## Features

- Responsive layout for desktop, tablet, and mobile
- Email address syntax validation
- Clear validation feedback
- Modern, accessible interface

## Tech Stack

- HTML, CSS, JavaScript

## Getting Started

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project Status and Limitations

This front-end demo checks email syntax only. It does not confirm mailbox existence or deliverability without a suitable API or backend.
